# School MUN

Сайт школьной Модели ООН. Обычные HTML, CSS и JavaScript, без сборки и сторонних библиотек. Все картинки и шрифты лежат в проекте.

## Где что находится

| Файл | Назначение |
| --- | --- |
| `public/index.html` | Структура страницы, тексты, меню и формы |
| `public/style.css` | Цвета, шрифты, сетка и мобильная версия |
| `public/committees.js` | Список комитетов, повестки и вопросы |
| `public/app.js` | Фильтры, сравнение, подбор комитета и чек-лист |
| `public/navigation.js` | Переключение разделов и история браузера |
| `public/motion.js` | Анимации карточек и диалогов |
| `public/hero.webp` | Главное изображение |
| `public/fonts/` | Шрифты Manrope и их лицензия |
| `.github/workflows/pages.yml` | Автоматическая публикация на GitHub Pages |

Скрипты подключены в конце `<head>` с `defer`: сначала данные комитетов, затем анимации, логика интерфейса и навигация. Порядок важен.

## Посмотреть локально

Откройте `public/index.html` в браузере. Если установлен Python, можно запустить HTTP-сервер из папки проекта:

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory public
```

На Windows вместо `python` можно написать `py`. Адрес: `http://localhost:8080`. Остановка: Ctrl+C.

## GitHub Pages

1. Загрузите файлы проекта в публичный репозиторий. Папка `public` должна находиться в корне репозитория.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**.
4. После отправки изменений в ветку `main` workflow опубликует сайт. При необходимости запустите его вручную через **Actions → Publish website → Run workflow**.
5. Адрес опубликованного сайта появится в **Settings → Pages**.

Обновления файлов в `main` автоматически публикуются. После успешной публикации компьютер можно выключить.

## Как менять сайт

Название школы, описание, контакты и разделы редактируются в `index.html`. Цвета задаются переменными в начале `style.css`.

Комитеты хранятся в массиве `committees`. У каждого есть `id`, `name`, `lang`, `level`, `topic`, `desc`, `questions`, `first` и `area`. Сохраняйте уникальные `id`. Для языка используйте `RU`, `EN` или `KZ`, для уровня — `beginner`, `middle` или `advanced`.

При добавлении комитетов обновите фиксированные числа и тексты в HTML. Счётчик результатов фильтра вычисляется автоматически.

Функции в `app.js` отвечают за отдельные действия: `renderCommittees` строит каталог, `openCommittee` открывает карточку, `openQuiz` показывает тест, `updateComparisonTray` обновляет панель сравнения, `updatePreparationProgress` обновляет прогресс подготовки.

Чек-лист хранится в `localStorage` браузера. Он не синхронизируется между устройствами. Подбор комитета использует простую систему баллов: совпадение уровня — 4, темы — 3; сложный комитет для новичка получает штраф 5.

## Что заполнить перед конференцией

Даты, место, контакты, регистрационную ссылку и реальные правила организаторов. Сейчас название и повестки служат примером. Серверной регистрации, отправки заявок и базы пользователей в проекте нет.

## Docker

Если нужен собственный сервер с Nginx:

```sh
docker compose up -d --build
```

Сайт откроется на порту 8080. Для остановки выполните `docker compose down`.
